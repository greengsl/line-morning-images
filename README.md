# LINE Morning Images

Daily morning images used by a private LINE Messaging API automation.

This public repository contains generated images only. It does not contain LINE credentials or recipient information.

Stock photos are provided by [Pexels](https://www.pexels.com/). Each dated JSON file records the photographer and original photo page.

Layouts rotate between square, portrait, and landscape. Weather data for Nantou and Taoyuan is provided by [Open-Meteo](https://open-meteo.com/).
